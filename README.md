# Screen Plays Through the 100 Years 🇿🇦

**Celebrating 100 Years of South African Film and Television**

## About the Project

Screen Plays Through the 100 Years started as a simple data-scraping exercise for a family quiz night and evolved into an interactive web application celebrating South African film and television.

The idea originated from a question: *How well do we know South African productions?*

We can often recognise actors from American films and television series, but how easily can we identify the cast members of locally produced and filmed South African content?

This project was created to explore that question by collecting information about South African productions, including films and television series, and making that information accessible through an interactive web experience.

What began as a small personal experiment became an opportunity to explore data collection, Python automation, database management, and AI-assisted application development.

## How It Was Built

The project brought together several technologies and development approaches:

- **Python:** Developed a web-scraping script to discover and collect information about South African film and television productions and their cast members.
- **Supabase:** Used Supabase as the backend database to store and manage the collected information.
- **Lovable:** Used AI-assisted development to accelerate the creation of the web application's user interface and overall experience.
- **Web Technologies:** Developed an interactive application to make the collected information accessible to users.

## Key Features

- Explore South African film and television productions.
- Discover actors and cast members from local productions.
- Access information collected through automated data scraping.
- Browse South African entertainment content through an interactive web interface.

## Development

Prefer working locally? You'll need **Node.js** and **npm** installed.

We recommend using [Node Version Manager (nvm)](https://github.com/nvm-sh/nvm#installing-and-updating) to manage your Node.js versions.

### 1. Clone the repository

```bash
git clone <this-repository-url>
```

### 2. Navigate into the project

```bash
cd <repository-name>
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application should now be accessible through the local development URL displayed in your terminal.

## Project Motivation

Beyond building an application, this project demonstrates how a simple idea can develop into a practical software solution through experimentation and the integration of different technologies.

It combines data scraping, data management, backend infrastructure, and AI-assisted frontend development to explore and celebrate South Africa's entertainment history.

**The bigger idea is simple: South African stories, productions, and talent deserve to be just as discoverable as international entertainment.** 🇿🇦
